# 🗳️ Voting

실시간 투표 웹사이트입니다. 외부 패키지 없이 Node.js만 있으면 바로 실행할 수 있습니다.

## 실행
- `start.bat` 더블클릭 (관리자 페이지가 자동으로 열립니다)
- 또는 터미널에서 `node server.js`

| 페이지 | 주소 |
|---|---|
| 투표 페이지 | http://localhost:3000/ |
| 관리자 페이지 | http://localhost:3000/admin |

기본 관리자 비밀번호: `admin1234` → `start.bat` 안의 `ADMIN_PASSWORD` 값을 바꾸세요.

## 기능
- **투표자**: 항목을 눌러 투표하고, 종료 전까지 다른 항목을 눌러 변경하거나 취소할 수 있습니다. 결과는 실시간으로 반영됩니다.
- **관리자**: 제목 변경, 항목 추가/수정/삭제, 실시간 결과 공개 ON/OFF, 투표 종료/재개, 투표 초기화, 참여용 QR 생성(크게 보기, PNG 다운로드).

## QR로 참여하려면
1. 휴대폰과 서버 컴퓨터가 **같은 Wi-Fi**에 연결되어 있어야 합니다.
2. 관리자 페이지의 QR 섹션에서 `http://192.168.x.x:3000/` 주소를 골라 **QR 생성**을 누르세요.
3. Windows 방화벽 팝업이 뜨면 **허용**을 눌러야 휴대폰에서 접속할 수 있습니다.

> 참고: 관리자 페이지의 QR 생성에는 인터넷 연결이 필요합니다(QR 라이브러리를 CDN에서 불러옵니다).
> 투표 데이터는 `data.json` 에 자동 저장되어 서버를 다시 켜도 유지됩니다.
> 같은 사람인지는 브라우저(기기) 단위로 구분합니다.
